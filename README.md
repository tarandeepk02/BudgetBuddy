# Budget Buddy - Track Today, Save Tomorrow.

## Project Overview
Budget Buddy is a Daily Expense Tracker system developed using the CodeIgniter PHP framework. It helps users keep track of their daily, monthly, and yearly expenses efficiently. This system is designed with a user-friendly interface, allowing users to manage and analyze their financial activities.

## Technologies Used
- **Language:** PHP 5.6, PHP 7.x, PHP 8.x
- **Database:** MySQL 5.x
- **User Interface:** HTML, AJAX, jQuery, JavaScript
- **Compatible Web Browsers:** Mozilla Firefox, Google Chrome, Internet Explorer 8+, Opera
- **Software Requirements:** XAMPP / WAMP / MAMP / LAMP

## Features
### User Module
- **Dashboard:** Users can view summarized expenses on a daily, monthly, and yearly basis.
- **Expenses:** Users can add and delete expenses.
- **Expense Report:** Users can generate reports based on daily, monthly, or yearly expense tracking.
- **Profile Management:** Users can update their profile details.
- **Change Password:** Users can update their login credentials.
- **Logout:** Users can securely log out from the system.
- **Password Recovery:** Users can recover their password if forgotten.

## Installation Guide
Follow these steps to set up and run Budget Buddy on your local server:

1. **Download** the zip file.
2. **Extract** the zip file and copy the `budgetbuddy` folder.
3. **Paste** the folder inside the root directory:
   - For XAMPP: `xampp/htdocs`
   - For WAMP: `wamp/www`
   - For LAMP: `/var/www/html`
4. **Set up the database:**
   - Open [PHPMyAdmin](http://localhost/phpmyadmin).
   - Create a database named `budgetbuddy`.
   - Import the `budgetbuddy.sql` file (found inside the `SQL` folder in the package).
5. **Run the project** by accessing it in your browser:
   ```
   http://localhost/BudgetBuddy
   ```
